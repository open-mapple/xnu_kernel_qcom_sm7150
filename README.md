# xnu_kernel_qcom_sm7150

SoC layer for the Qualcomm SM7150 (Snapdragon 730/730G/732G), laid over xnu_kernel_qcom_common.

For now this repository is empty: almost all SM7150 support lives in xnu_kernel_qcom_common, which carries the kernel code for the Xiaomi Redmi Note 10 Pro (sweet) and the Google Pixel 4a (sunfish). Code that is specific to SM7150 will move here once it has been separated from the shared Qualcomm drivers.
